## Recommendation from the V&V agent

**Accept with limitations** for the intended use, if the V&V Report shows every acceptability criterion met:

1. Results are relative comparisons between measures on a notional site, not predictions for any real site.
2. Mobile-sensor detection (drone, robot dog, vehicle, guards) is range-based and probably optimistic (hazard H-02,
   backlog B-04): measures that add mobile sensors are compared less reliably than fixed-camera measures.
3. Daylight and dry weather only (backlog B-05).
4. Where the V&V Report marks measures as tied, the order between them rests on cost and ORION's judgment, not on a
   measured difference.
5. No field-data validation (backlog B-11): not for use on a real facility.
